# 开工先 · 反拖延 AI 工作台

把一个让你头大的任务，拆成今天就能做完的一小步；每一步都有 deadline 和「做到哪算完」的验收标准——治拖延，也治完美主义。

WaytoAGI 1024 办公赛道作品 · 用豆包工作搭的 AI 工作台。

- 在线版（豆包链接）：https://4mbszp31sr2x2.doubao.link/app/app_17gra8uj9k9
- GitHub Pages 版：https://javenzheng.github.io/kaigongxian/

## 功能
1. 输入大任务 + 截止日期，生成「开工先」拆分提示词，复制给豆包工作，回复粘贴回来自动排期。
2. 今日工作台：每天只显示今天该做的 2~3 步，做完打勾。
3. 全部微任务：按 deadline 倒排，可手动添加、导出/导入备份。

## 使用
直接打开 index.html（或线上链接）即可。数据只存在浏览器本地。
